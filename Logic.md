
# Quantifiers

- $\forall$ : Universal Quantifier (for all / for every)
    - for all $M > 0$
    * It means the statement/equation must hold for every single positive value of $M$ (a very strict condition)
- $\exists$ : Existential Quantifier (for some / there exists)
    - for some $M > 0$
    * It means there exists at least one positive value of $M$ that satisfies the equation (you just need to find one working value).
